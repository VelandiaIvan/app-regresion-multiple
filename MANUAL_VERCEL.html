Publique su app en Vercel

De los archivos en su computador a una dirección web propia, en 8 pasos. Manual del Asistente de Regresión Lineal Múltiple.

⏱ unos 45 minutos🧰 nivel principiante☑ marque cada paso: su avance se guarda
Lea esto primero: Vercel no puede ejecutar esta app

La app está hecha con Streamlit, que necesita un servidor encendido todo el tiempo con una conexión WebSocket abierta. Las funciones de Vercel son «sin servidor» (se encienden, responden y se apagan) y no admiten WebSockets. Si sube la app tal cual a Vercel, no funciona.

Lo que sí funciona, y lo que hace este manual: la app corre en Streamlit Community Cloud (gratis) y usted publica en Vercel una página suya —con su dirección y, si quiere, su dominio— que muestra la app dentro. La persona entra por Vercel; los cálculos se hacen en Streamlit.

⚠ Dos condiciones que conviene conocer antes de empezar

1) El plan gratuito de Vercel es solo para uso personal y no comercial (así lo indica su documentación). Si esta página la va a usar con clientes, en una empresa o en un banco, necesitará el plan Pro u otra alternativa. Revise las condiciones vigentes en vercel.com.

2) La app de Streamlit debe ser pública para poder mostrarse dentro de otra página. Streamlit indica que no hay soporte oficial para incrustar apps privadas. Además, todo archivo que alguien cargue en la app pasa por servidores de Streamlit: no use datos confidenciales (cartera real, estudio de Manizales).

2Subir el código a GitHub

⏱ 5 min · detalle ampliado en DESPLIEGUE.md, apartado 4

Abra PowerShell y entre a la carpeta del proyecto

cd C:\Users\DELL\Desktop\app_regresion
git status

Debe ver, entre los archivos nuevos, la carpeta vercel/ y este manual MANUAL_VERCEL.html.

Retire del seguimiento los archivos compilados (.pyc)

git rm -r --cached core/__pycache__

Si responde pathspec ... did not match any files, ya estaban retirados: continúe.

Confirme y suba

git add .
git commit -m "App de regresion lineal multiple y pagina para Vercel"
git push origin main

La primera vez, Git puede abrir una ventana para iniciar sesión en GitHub. Los avisos «LF will be replaced by CRLF» son normales en Windows.

Compruebe en GitHub

Entre a github.com/velandiaivan640-droid/app-regresion-multiple y confirme que ve app.py, core/, ui/ y vercel/index.html.

3Publicar la app en Streamlit Community Cloud

⏱ 10 min (la instalación tarda unos minutos)

Entre con GitHub

Vaya a share.streamlit.io y pulse Continue with GitHub. Si su repositorio es privado, GitHub pedirá un permiso adicional (alcance repo): acéptelo.

Cree la app

Arriba a la derecha pulse Create app y elija Yup, I have an app.

Complete el formulario

Branchmain

Elija Python 3.12

Pulse Advanced settings → en Python version escoja 3.12 → Save. Deje Secrets vacío.

Esta versión no se puede cambiar después: habría que borrar la app y desplegarla de nuevo. Elíjala siempre de forma explícita.

Despliegue y espere

Pulse Deploy. Instalar las dependencias tarda unos minutos; verá el avance en el panel de logs. Termina cuando aparece el menú de 13 módulos.

Copie la dirección de su app

Tendrá la forma https://regresion-multiple.streamlit.app. Guárdela: la necesita en el paso 4.

Compruebe que es pública

Abra esa dirección en una ventana de incógnito. Debe abrir la app sin pedir inicio de sesión. Si pide iniciar sesión, la app es privada y no se podrá mostrar dentro de la página de Vercel: revise las opciones de visibilidad en el menú Share de la app.

4Configurar la página de Vercel

⏱ 5 min · la carpeta vercel/ ya viene lista

La carpeta vercel/ contiene solo dos archivos: index.html (la página con el marco) y vercel.json (ajustes de seguridad básicos). Lo único que debe cambiar es una línea.

Abra vercel/index.html con el Bloc de notas o con VS Code

Busque esta línea (está cerca del inicio):

const APP_URL = "https://TU-APP.streamlit.app";

Reemplace la dirección por la de su app

const APP_URL = "https://regresion-multiple.streamlit.app";

Sin ?embed=true al final: la página lo agrega sola. Guarde el archivo.

Pruébela en su computador

cd C:\Users\DELL\Desktop\app_regresion\vercel
py -3.12 -m http.server 8080

Abra http://localhost:8080: debe ver el encabezado azul y, debajo, la app cargando. Para detener el servidor pulse Ctrl + C. Si en lugar de la app ve una tarjeta amarilla «Falta un paso», la dirección sigue sin configurar.

Suba el cambio a GitHub

cd C:\Users\DELL\Desktop\app_regresion
git add .
git commit -m "Configurar la direccion de la app en la pagina de Vercel"
git push origin main

5Desplegar en Vercel

⏱ 10 min · elija una de las dos opciones

Ventaja: después, cada vez que haga git push, Vercel actualiza la página solo. Recomendada.

Entre a Vercel con GitHub

En vercel.com pulse Sign Up y elija continuar con GitHub.

Cree un proyecto nuevo e importe el repositorio

Abra vercel.com/new. Conecte su cuenta de GitHub si se lo pide y elija el repositorio app-regresion-multiple.

⚠ Indique que la página está en la carpeta vercel (Root Directory)

Si en la pantalla de configuración ve el campo Root Directory, escriba vercel.

Este es el error más probable. Sin este ajuste, Vercel mira la raíz del repositorio, que es una aplicación de Python (app.py, requirements.txt), y el despliegue puede fallar. Si el primer despliegue falla: Settings → Build and Deployment → Root Directory → escriba vercel → Save → vuelva a desplegar.

Framework: «Other», sin comando de compilación

Si no detecta ningún framework, Vercel selecciona Other. Es una página estática: no hay nada que compilar. En Build Command no escriba nada.

Pulse Deploy

En un minuto aparece una dirección como https://su-proyecto.vercel.app. Esa es la dirección pública de su app. Ábrala.

Ventaja: no depende de la configuración de la interfaz web y evita el error del Root Directory, porque sube solo la carpeta vercel/. Desventaja: cada actualización es manual (vercel --prod).

Instale Node.js 20 o superior y compruébelo

node --version

Si no lo reconoce, instálelo desde nodejs.org y cierre y vuelva a abrir PowerShell.

Instale la herramienta de Vercel e inicie sesión

npm i -g vercel
vercel login

Siga las indicaciones en pantalla para autenticarse con su cuenta.

Entre a la carpeta de la página y despliegue

cd C:\Users\DELL\Desktop\app_regresion\vercel
vercel

Responda las preguntas con las opciones que propone (Enter) y elija el nombre del proyecto. Al terminar, la terminal muestra la dirección. El primer despliegue de un proyecto nuevo siempre es de producción.

Para publicar cambios posteriores

cd C:\Users\DELL\Desktop\app_regresion\vercel
vercel --prod

6Dominio propio (opcional)

⏱ 15 min + el tiempo de propagación del DNS · Vercel ya le da una dirección .vercel.app gratis

Agregue el dominio al proyecto

En Vercel abra su proyecto → Settings → Domains → botón Add Existing y escriba el dominio. ¿No tiene uno? Vercel permite comprarlo.

Cree el registro DNS que Vercel le indica, en el sitio donde compró el dominio

Si usa…Tipo de registro
Un subdominio (p. ej. regresion.midominio.com)CNAME (cada proyecto tiene su valor propio)
El dominio raíz (p. ej. midominio.com)A

Copie los valores exactos que muestra Vercel en la pantalla de Domains; no use los de otro proyecto.

Espere a que quede configurado

Los cambios de DNS tardan en propagarse. Cuando Vercel lo verifica, el estado del dominio cambia a configurado. Si muestra Invalid Configuration, revise que no haya registros A, AAAA o CNAME en conflicto para el mismo nombre.

!Problemas frecuentes

Haga clic en el síntoma

Veo una tarjeta amarilla que dice «Falta un paso»

La dirección APP_URL sigue siendo la de ejemplo (TU-APP), o la cambió pero no volvió a desplegar. Repita el paso 4 y vuelva a desplegar la página.

El marco sale en blanco o dice «refused to connect»

Lo más probable es que la app de Streamlit no sea pública (Streamlit no da soporte a incrustar apps privadas) o esté todavía arrancando. Abra la dirección de Streamlit en incógnito: si pide iniciar sesión, es privada (paso 3.7). Mientras tanto, use el botón «Abrir en pestaña nueva».

Vercel dice «Build failed» o se queja de Python

Casi seguro falta el Root Directory: Settings → Build and Deployment → Root Directory → vercel → Save → vuelva a desplegar (paso 5, opción A).

Aparece «404: NOT_FOUND» en la dirección .vercel.app

Confirme que index.html está dentro de la carpeta vercel/ en GitHub y que el Root Directory apunta a ella. Con la opción B, ejecute vercel --prod estando dentro de vercel/.

«vercel» no se reconoce como comando

Falta Node.js o no reinició la terminal. Ejecute node --version; si falla, instale Node.js 20+ desde nodejs.org, cierre y abra PowerShell, y repita npm i -g vercel.

Cambié la dirección y sigo viendo lo anterior

O no se volvió a desplegar la página, o el navegador guardó la versión vieja. Compruebe que el despliegue terminó en Vercel y recargue con Ctrl + F5.

Vercel me pide pasar a un plan de pago o pausa el proyecto

El plan gratuito (Hobby) es solo para uso personal no comercial. Si el uso es comercial necesita el plan Pro. Revise las condiciones en vercel.com.

El dominio propio dice «Invalid Configuration»

Compare los registros DNS con los valores que muestra Settings → Domains de su proyecto y elimine registros A, AAAA o CNAME en conflicto. Los cambios de DNS tardan en propagarse.

Dentro del marco algo se comporta distinto que en la app directa

No verifiqué cómo se comportan, dentro de un marco, todas las funciones (carga de archivos, descargas, memoria de la sesión). Use el botón «Abrir en pestaña nueva», que abre la app sin marco.

Fallos de Streamlit al desplegar (instalación, Python, «in the oven»)

Están resueltos en DESPLIEGUE.md, apartado 9.

B¿Y si necesito todo dentro de Vercel?

Solo lectura: esta ruta no forma parte del manual

Esta aplicación no puede ejecutarse como está en Vercel. Para que el cálculo corra en Vercel habría que cambiar el diseño:

  • Reescribir la interfaz de los 13 módulos como una aplicación web (p. ej. Next.js) en lugar de Streamlit.
  • Convertir el motor (core/, que sí es reutilizable) en una API sin estado: cada petición debe traer sus datos, porque las funciones de Vercel no guardan la sesión entre llamadas.
  • Comprobar límites de tamaño: pandas, scipy y statsmodels son librerías pesadas y pueden chocar con los límites de las funciones. No lo verifiqué.

Su otro proyecto (el zip con frontend/ y backend/) sigue ese patrón: interfaz web aparte y API de Python aparte. Si quiere llevar esta app a ese modelo, pídalo como un proyecto nuevo.
